# 단계별 로드맵

> **"비전을 현실로 — Phase 0부터 Phase 3까지, 단계마다 검증하고 성장한다."**

---

## 로드맵 철학

COSY Portal은 한 번에 완성되는 제품이 아닙니다. 각 Phase에서 **핵심 가설을 검증**하고, 검증된 기반 위에 다음 단계를 쌓아올립니다. 검증 없이 다음 단계로 넘어가는 것은 금지합니다.

::: warning 핵심 원칙
각 Phase의 성공 지표(Success Metrics)를 달성하지 못하면, 다음 Phase로 진행하기 전에 반드시 원인 분석과 수정이 선행되어야 합니다.
:::

## Phase 0: 기획 및 합의 (NOW ~ Q2 2026)

> "무엇을, 왜, 어떻게 만들 것인가를 확정한다."

### 핵심 목표
- COSY Portal 비전 확정 및 양사 합의
- JV 구조 합의 (법인 형태, 수익 배분)
- API 설계 초안 및 기술 스택 확정

### 산출물

| 산출물 | 담당 | 상태 |
|--------|------|------|
| 비전 선언문 / 5대 축 정의 | EP | 진행 중 |
| JV MOU 초안 | 양사 | 대기 |
| API Hub 스펙 v0.1 | EP + GlowUpRise | 대기 |
| UI/UX 와이어프레임 v0.1 | EP | 대기 |
| 기술 스택 결정 | EP | 대기 |

### 성공 지표

- 양사 대표 비전 합의 완료
- MOU 체결
- API 스펙 v0.1 양사 리뷰 완료

## Phase 1: 일상화 + 소속감 (Q3-Q4 2026)

> "크리에이터가 매일 COSY를 열고, COSY 소속임을 자랑한다."

### 핵심 목표
- COSY Portal 첫 버전 런칭
- 크리에이터가 매일 접속하는 홈 대시보드 구현
- 소속감을 느끼게 하는 아이덴티티 시스템 도입

### 주요 기능

| 기능 | 설명 | 축 |
|------|------|-----|
| 홈 대시보드 | 오늘의 매출, 할 일, 알림을 한눈에 | 일상화 |
| 오늘의 브리핑 | AI가 생성하는 일일 비즈니스 요약 | 일상화 |
| @cosy.me 이메일 | 크리에이터 전용 이메일 주소 | 소속감 |
| 인증 마크 | SNS 프로필에 사용하는 COSY 인증 배지 | 소속감 |
| 크리에이터 프로필 | COSY 내 공식 프로필 페이지 | 소속감 |

### 리소스

| 역할 | 인원 | 담당 |
|------|------|------|
| 프론트엔드 개발 | 2명 | EP |
| 백엔드/API 개발 | 1명 | GlowUpRise |
| UI/UX 디자인 | 1명 | EP |
| PM | 1명 (공유) | 양사 |

### 성공 지표

| 지표 | 목표 |
|------|------|
| MAU (월간 활성 사용자) | 500명 |
| DAU/MAU 비율 | 30% 이상 |
| @cosy 이메일 발급률 | 가입자 대비 60% |
| NPS (순추천지수) | 40 이상 |

## Phase 2: 솔루션 (Q1-Q2 2027)

> "크리에이터의 업무 도구가 COSY 안에서 완결된다."

### 핵심 목표
- 크리에이터가 외부 도구 없이 COSY 안에서 업무 수행
- 통합 커뮤니케이션 시스템 도입
- 크루 협업 기능 강화

### 주요 기능

| 기능 | 설명 | 대체 대상 |
|------|------|----------|
| 통합 메신저 | DM, 그룹 채팅, 크루 채널 | 카카오톡, 텔레그램 |
| COSY Mail | @cosy.me 기반 이메일 클라이언트 | Gmail, Naver |
| 파일 저장소 | 크리에이터 전용 클라우드 스토리지 | Google Drive |
| 크루 워크스페이스 | 크루 전용 협업 공간 | Notion, Slack |
| 캘린더 | 콘텐츠 일정 + 비즈니스 일정 통합 | Google Calendar |

### 리소스

| 역할 | 인원 | 담당 |
|------|------|------|
| 프론트엔드 개발 | 3명 | EP |
| 백엔드/API 개발 | 2명 | GlowUpRise |
| UI/UX 디자인 | 1명 | EP |
| PM | 1명 | EP |
| QA | 1명 | 양사 |

### 성공 지표

| 지표 | 목표 |
|------|------|
| MAU | 2,000명 |
| 메신저 DAU | MAU의 50% |
| 외부 도구 사용 감소율 | 40% 감소 |
| 크루 협업 기능 사용률 | 크루 보유 크리에이터의 60% |

## Phase 3: 인프라 (Q3 2027+)

> "크리에이터가 도구를 쓰는 것을 넘어, 도구를 만든다."

### 핵심 목표
- Agent Builder, Dashboard Builder 런칭
- Marketplace 오픈
- 네트워크 효과 시작

### 주요 기능

| 기능 | 설명 | 비고 |
|------|------|------|
| Agent Builder | 노코드 AI 에이전트 생성 플랫폼 | 핵심 차별화 |
| Dashboard Builder | 드래그 앤 드롭 대시보드 생성 | |
| Marketplace | 에이전트/대시보드 거래 생태계 | COSY Cash Points |
| API Hub v2 | 외부 API 연동 확장 | Shopify, YouTube 등 |

### 리소스

| 역할 | 인원 | 담당 |
|------|------|------|
| 프론트엔드 개발 | 4명 | EP |
| 백엔드/API 개발 | 3명 | EP + GlowUpRise |
| AI/ML 엔지니어 | 2명 | EP |
| UI/UX 디자인 | 2명 | EP |
| PM | 2명 | 양사 |
| QA | 1명 | 양사 |

### 성공 지표

| 지표 | 목표 |
|------|------|
| MAU | 10,000명 |
| 마켓플레이스 등록 에이전트/대시보드 | 500+ |
| 마켓플레이스 월 거래액 | 2,500만원 |
| Agent Builder 월 활성 사용자 | MAU의 15% |

::: tip 인프라가 시작되면 게임이 바뀐다
Phase 3에서 네트워크 효과가 작동하기 시작하면, 크리에이터가 크리에이터를 불러오는 선순환이 만들어집니다. 이 시점부터 COSY는 "도구"에서 "생태계"로 진화합니다.
:::

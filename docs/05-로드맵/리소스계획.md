# 리소스 계획

> **"비전만으로는 부족하다 — 사람, 예산, 기술이 뒷받침되어야 한다."**

---

## 리소스 계획 원칙

COSY Portal은 단계별로 성장하며, 각 Phase에 필요한 리소스도 단계적으로 투입합니다. **과도한 선투자 없이, 검증된 성과에 비례하여 리소스를 확대**하는 것이 원칙입니다.

::: info 린 스타트업(Lean Startup) 접근
Phase 0-1은 최소 인원으로 빠르게 검증하고, Phase 2-3에서 검증된 모델에 본격 투자합니다.
:::

## 핵심 채용 계획 (Key Hires)

| 우선순위 | 포지션 | 필요 시점 | 핵심 역량 |
|---------|--------|----------|----------|
| 1 | 시니어 프론트엔드 개발자 | Phase 1 시작 | React/Next.js, 디자인 시스템 구축 경험 |
| 2 | 시니어 백엔드 개발자 | Phase 1 시작 | API 설계, 실시간 처리, 보안 |
| 3 | AI/ML 엔지니어 | Phase 2 중반 | LLM 파인튜닝, 에이전트 아키텍처 |
| 4 | 프로덕트 디자이너 | Phase 1 시작 | 크리에이터 도구 UX, 대시보드 설계 |
| 5 | 두 번째 PM | Phase 3 시작 | 마켓플레이스/플랫폼 운영 경험 |

::: tip 초기 핵심 인력
Phase 1의 성패를 좌우하는 것은 **시니어 프론트엔드 1명 + 프로덕트 디자이너 1명**입니다. 이 두 포지션을 최우선으로 확보해야 합니다.
:::

## 기술 스택 (Technology Stack)

| 레이어 | 기술 | 선택 이유 |
|--------|------|----------|
| 프론트엔드 | Next.js (App Router) + TypeScript | SEO, 성능, 생산성 |
| UI 라이브러리 | Tailwind CSS + Radix UI | 커스터마이징 용이, 접근성 |
| 백엔드 | Node.js (Bun) + Hono | 경량, 빠른 개발, EP 기존 스택 |
| 데이터베이스 | PostgreSQL + Redis | 안정성, 캐싱, 실시간 |
| AI 인프라 | OpenAI API + Anthropic API | 에이전트 엔진, 텍스트 분석 |
| 인프라 | Vercel (프론트) + AWS/GCP (백엔드) | 프론트 배포 최적화, 백엔드 유연성 |
| 실시간 통신 | WebSocket (Socket.io) | 메신저, 라이브 대시보드 |
| 파일 저장소 | S3 호환 스토리지 (R2/S3) | 비용 효율, 확장성 |

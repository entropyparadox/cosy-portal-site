# Dashboard Builder

> **"드래그 앤 드롭으로 나만의 데이터 뷰를 만든다."**

---

## 왜 대시보드 빌더인가

크리에이터에게 데이터는 있지만, 데이터를 **보는 방법**이 없습니다. 매출 추이, 크루원 성과, 상품 실적을 한눈에 파악할 수 있는 대시보드는 지금까지 엔지니어의 영역이었습니다. Dashboard Builder는 이 장벽을 허물어, 누구나 코딩 없이 **자신의 비즈니스를 시각화**할 수 있게 합니다.

::: info 대시보드 빌더 = 크리에이터의 Notion + Tableau
Notion처럼 쉽고, Tableau처럼 강력합니다. COSY의 실시간 데이터와 연결된 라이브 대시보드를 드래그 앤 드롭으로 만듭니다.
:::

---

## 위젯 라이브러리 (Widget Library)

50+ 위젯을 자유롭게 배치하여 나만의 대시보드를 구성합니다.

| 카테고리 | 위젯 예시 | 데이터 소스 |
|---------|----------|-----------|
| 매출 차트 | 일일/주간/월간 매출 추이, 상품별 매출 파이 차트, 목표 대비 달성률 | 매출 DB |
| 크루 현황 | 크루원 활동 현황, 역할별 기여도, 성과 랭킹 보드 | 크루 DB |
| 상품 실적 | 상품별 판매량, 재고 현황, 재구매율 히트맵 | 상품 DB, 주문 DB |
| 정산 내역 | 월별 정산 요약, 수수료 내역, 세금 계산 현황 | 정산 DB |
| 고객 분석 | 고객 세그먼트, 유입 경로, LTV 분포, 이탈 예측 | 고객 DB |

### KPI 카드 위젯

핵심 지표를 한 장의 카드로 보여줍니다.

```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│  오늘 매출       │  │  이번 달 주문     │  │  활성 크루원      │
│  ₩2,450,000     │  │  1,247건         │  │  23명            │
│  ▲ 12% vs 어제  │  │  ▲ 8% vs 전월   │  │  ▼ 2명 vs 전주   │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

## 대시보드 구성 방법

### 1. 레이아웃 설정

- 그리드 기반 자유 배치 (반응형 자동 조정)
- 템플릿 레이아웃 선택 또는 빈 캔버스 시작
- 탭/페이지 분리로 대시보드 그룹화

### 2. 데이터 바인딩

- COSY 내부 데이터 원클릭 연결
- 외부 API 연동 (Google Analytics, YouTube Studio 등)
- 커스텀 필터 및 날짜 범위 설정
- 실시간(WebSocket) 또는 주기적(Polling) 업데이트 선택

### 3. 시각화 커스터마이징

- 차트 타입: 라인, 바, 파이, 도넛, 히트맵, 테이블
- 색상 테마 설정 (브랜드 컬러 적용 가능)
- 조건부 서식 (목표 미달 시 빨간색 등)
- 비교 기간 설정 (전일/전주/전월/전년)

## 공유 및 협업

| 기능 | 설명 |
|------|------|
| 크루 공유 | 특정 크루원에게 대시보드 읽기/편집 권한 부여 |
| 링크 공유 | 비밀번호 보호된 외부 공유 링크 생성 |
| 임베드 | 외부 웹사이트에 대시보드 위젯 삽입 |
| 스냅샷 | 특정 시점의 대시보드를 이미지/PDF로 내보내기 |
| 스케줄 리포트 | 정기적으로 대시보드 스냅샷을 이메일/메신저로 발송 |

::: tip 크루와 함께 보는 대시보드
크리에이터 혼자만 보는 대시보드가 아닙니다. 크루원 각자의 역할에 맞는 뷰를 설정하여 팀 전체가 같은 데이터를 기반으로 의사결정합니다.
:::

## 마켓플레이스 연동

대시보드도 에이전트와 마찬가지로 마켓플레이스에서 **판매**할 수 있습니다.

- **판매 가능 항목**: 대시보드 템플릿 (레이아웃 + 위젯 구성 + 데이터 바인딩 설정)
- **구매자 경험**: 원클릭 설치 → 자신의 COSY 데이터 자동 연결
- **카테고리**: 뷰티 크리에이터용, 패션 크리에이터용, MCN 관리자용 등
- **수익 배분**: 판매 금액의 80%가 제작자에게

::: info 대시보드 마켓플레이스 시나리오
뷰티 크리에이터 A가 "화장품 브랜드 성과 분석 대시보드"를 만들어 마켓플레이스에 등록합니다. 비슷한 카테고리의 크리에이터 B, C가 이를 구매하여 자신의 데이터로 바로 활용합니다. A는 추가 수익을 얻고, B와 C는 처음부터 만들 필요 없이 검증된 대시보드를 사용합니다.
:::

## 기대 효과

- **데이터 민주화**: 엔지니어 없이도 크리에이터가 직접 데이터 분석
- **의사결정 속도 향상**: 필요한 정보를 한눈에 파악
- **크루 협업 강화**: 팀 전체가 동일한 데이터 기반으로 소통
- **추가 수익원**: 우수 대시보드를 마켓플레이스에서 판매

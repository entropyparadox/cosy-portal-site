# COSY API Hub

> **"Portal과 Platform을 잇는 데이터의 다리."**

---

## 왜 API Hub인가

COSY Portal(크리에이터가 보는 화면)과 COSY Platform(데이터가 흐르는 백엔드)은 별개의 시스템입니다. API Hub는 이 두 세계를 연결하는 **중앙 브릿지(Bridge)** 역할을 합니다. Agent Builder, Dashboard Builder, 그리고 마켓플레이스의 모든 도구가 API Hub를 통해 데이터를 읽고 씁니다.

::: info 아키텍처 핵심 원칙
모든 데이터 접근은 API Hub를 경유합니다. Portal의 프론트엔드가 Platform의 DB에 직접 접근하는 것은 허용되지 않습니다. 이 원칙이 보안, 확장성, 그리고 두 회사 간 역할 분리를 보장합니다.
:::

## COSY 내부 API

Platform(glowuprizz)이 제공하는 핵심 데이터 API입니다.

| API 도메인 | 엔드포인트 예시 | 설명 |
|-----------|---------------|------|
| 매출 데이터 | `/sales/daily`, `/sales/products`, `/sales/trends` | 일별/상품별/기간별 매출 조회 |
| 크루 관계 | `/crew/members`, `/crew/roles`, `/crew/activity` | 크루원 목록, 역할, 활동 내역 |
| 상품 정보 | `/products/list`, `/products/inventory`, `/products/reviews` | 상품 카탈로그, 재고, 리뷰 |
| 정산/세금 | `/settlement/monthly`, `/settlement/tax`, `/settlement/history` | 월별 정산, 세금 계산, 이력 |
| 고객 분석 | `/customers/segments`, `/customers/ltv`, `/customers/churn` | 고객 세그먼트, LTV, 이탈 예측 |
| 콘텐츠 메트릭 | `/content/performance`, `/content/schedule`, `/content/engagement` | 콘텐츠 성과, 일정, 인게이지먼트 |

## 외부 연동 API (External Integrations)

크리에이터의 외부 플랫폼 데이터를 통합합니다.

| 플랫폼 | 연동 데이터 | 인증 방식 |
|--------|-----------|----------|
| Shopify | 주문, 상품, 고객, 재고 | OAuth 2.0 |
| Cafe24 | 주문, 상품, 회원, 쿠폰 | OAuth 2.0 |
| YouTube Analytics | 조회수, 구독자, 수익, 인구통계 | Google OAuth |
| Instagram Insights | 도달, 인게이지먼트, 팔로워, 스토리 | Meta Graph API |
| Google Analytics | 트래픽, 전환, 사용자 행동 | Google OAuth |
| TikTok Analytics | 조회수, 팔로워, 트렌딩 | TikTok API |

::: tip 점진적 연동 전략
Phase 1에서는 COSY 내부 API만 개방하고, Phase 2부터 외부 API를 순차적으로 추가합니다. 크리에이터가 가장 많이 사용하는 플랫폼부터 우선 연동합니다.
:::

## API Hub 핵심 기능

### 인증 및 권한 관리 (Authentication & Authorization)

| 수준 | 접근 범위 | 대상 |
|------|----------|------|
| 크리에이터 본인 | 자신의 모든 데이터 읽기/쓰기 | 크리에이터 계정 |
| 크루원 | 크리에이터가 허용한 데이터 읽기 | 크루 멤버 |
| 에이전트 | 에이전트 생성 시 설정한 범위 | Agent Builder |
| 마켓플레이스 에이전트 | 구매자가 승인한 범위만 | 마켓 구매 에이전트 |

### 레이트 리밋 (Rate Limiting)

```
무료 플랜:   1,000 요청/일
스탠다드:    10,000 요청/일
프리미엄:    100,000 요청/일
엔터프라이즈: 무제한 (별도 협의)
```

### 로깅 및 모니터링

- 모든 API 호출 로그 기록 (who, what, when)
- 이상 패턴 탐지 (비정상적 대량 호출 등)
- 크리에이터별 사용량 대시보드 제공

## 데이터 보안 원칙

::: warning 크리에이터 데이터 보호
크리에이터의 비즈니스 데이터는 가장 민감한 자산입니다. API Hub는 다음 원칙을 반드시 지킵니다.
:::

1. **데이터 격리**: 크리에이터 A의 데이터에 크리에이터 B가 접근 불가
2. **최소 권한**: 에이전트는 필요한 최소한의 데이터만 접근
3. **감사 추적**: 모든 데이터 접근에 대한 완전한 로그 보존
4. **암호화**: 전송 중(TLS) 및 저장 시(AES-256) 암호화

---

## 기대 효과

- **개발 속도 향상**: 표준화된 API로 에이전트/대시보드 개발 가속
- **보안 강화**: 중앙 집중 인증/권한 관리로 데이터 보호
- **확장성**: 새로운 데이터 소스 추가 시 API 레벨에서 통합
- **파트너 생태계**: 외부 개발자도 API Hub를 통해 COSY 생태계에 참여 가능

# Marketplace

> **"크리에이터가 만들고, 크리에이터가 거래하는 AI 도구 생태계."**

---

## 왜 마켓플레이스인가

Agent Builder와 Dashboard Builder는 강력한 도구이지만, 모든 크리에이터가 직접 만들 필요는 없습니다. 어떤 크리에이터는 **만드는 데** 뛰어나고, 어떤 크리에이터는 **쓰는 데** 뛰어납니다. Marketplace는 이 두 그룹을 연결하여, 만드는 사람은 수익을 얻고 쓰는 사람은 시간을 절약하는 **생태계**를 형성합니다.

::: tip 앱스토어 모델의 크리에이터 버전
Apple App Store가 개발자와 사용자를 연결했듯이, COSY Marketplace는 **에이전트/대시보드 제작자**와 **사용자 크리에이터**를 연결합니다.
:::

---

## 거래 대상

| 카테고리 | 설명 | 예시 |
|---------|------|------|
| AI 에이전트 | Agent Builder로 만든 자동화 에이전트 | 매출 분석봇, 고객 응대봇, 콘텐츠 기획봇 |
| 대시보드 | Dashboard Builder로 만든 데이터 뷰 | 뷰티 크리에이터 성과판, MCN 관리 대시보드 |
| 에이전트 번들 | 여러 에이전트를 묶은 패키지 | "커머스 올인원 패키지" (매출+재고+고객) |
| 템플릿 | 에이전트/대시보드의 커스터마이징 시작점 | 업종별 맞춤 템플릿 |

---

## 거래 통화: COSY Cash Points

마켓플레이스의 모든 거래는 **COSY Cash Points**로 이루어집니다.

| 항목 | 설명 |
|------|------|
| 충전 | 원화(KRW)로 포인트 충전 |
| 사용 | 에이전트/대시보드 구매, 프리미엄 기능 이용 |
| 환급 | 판매 수익 포인트를 원화로 환급 (월 1회) |
| 보너스 | 리뷰 작성, 첫 구매, 이벤트 참여 시 보너스 지급 |

---

## 수익 배분 구조 (Revenue Split)

```
판매 금액 100%
├── 80% → 크리에이터 (제작자)
└── 20% → COSY (플랫폼 수수료)
     ├── 10% 인프라 운영
     ├── 5% 마케팅/프로모션
     └── 5% 품질 관리/심사
```

::: info 업계 최고 수준의 크리에이터 수익률
Apple App Store의 개발자 수익률은 70%, Google Play도 70%입니다. COSY Marketplace는 **80%**를 크리에이터에게 돌려줌으로써 제작 인센티브를 극대화합니다.
:::

## 마켓플레이스 기능

### 검색 및 발견

- **카테고리 탐색**: 업종별, 기능별, 인기순, 최신순
- **AI 추천**: 크리에이터의 비즈니스 유형에 맞는 도구 자동 추천
- **트렌딩 보드**: 주간/월간 인기 에이전트 랭킹

### 리뷰 시스템

| 요소 | 설명 |
|------|------|
| 별점 | 1-5점 평가 |
| 텍스트 리뷰 | 사용 경험 상세 후기 |
| 사용 통계 | 설치 수, 활성 사용자 수, 평균 사용 시간 |
| 인증 배지 | COSY 검증 에이전트 마크 |

### 사용량 추적 (Usage Tracking)

판매자와 구매자 모두에게 투명한 사용 데이터를 제공합니다.

- **판매자 대시보드**: 판매량, 수익, 사용자 피드백, 이탈률
- **구매자 대시보드**: 설치한 에이전트 목록, 사용 빈도, ROI 추정

## 네트워크 효과 (Network Effect)

마켓플레이스의 가장 강력한 특성은 **자기 강화 네트워크 효과**입니다.

```
                    ┌──────────────────┐
                    │  더 많은 크리에이터  │
                    │    유입 (사용자)    │
                    └────────┬─────────┘
                             │
                             ▼
┌──────────────────┐   ┌──────────────┐
│  생태계 가치 상승   │ ← │ 더 많은 에이전트 │
│  (해자 강화)       │   │  마켓 등록     │
└──────────────────┘   └──────┬───────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │  제작자 수익 증가   │
                    │  → 품질 향상       │
                    └──────────────────┘
```

::: warning 임계점(Critical Mass) 달성이 핵심
네트워크 효과는 일정 규모 이상의 참여자가 모여야 작동합니다. Phase 1-2에서 COSY가 직접 고품질 에이전트/대시보드를 제작하여 마켓플레이스를 시딩(Seeding)하고, 초기 제작자에게 인센티브를 제공하는 전략이 필요합니다.
:::

---

## 마켓플레이스 성장 전략

| 단계 | 전략 | 목표 |
|------|------|------|
| 시딩 (Seeding) | COSY 자체 제작 에이전트 50+ 등록 | 초기 콘텐츠 확보 |
| 초대 (Invite) | 파워 크리에이터 30명 초대, 제작 인센티브 제공 | 커뮤니티 핵심 형성 |
| 개방 (Open) | 전체 크리에이터에게 제작 도구 개방 | 자생적 성장 시작 |
| 가속 (Accelerate) | 월간 베스트 에이전트 시상, 프로모션 | 네트워크 효과 가속 |

---

## 기대 효과

- **크리에이터 신규 수익원**: 에이전트/대시보드 판매로 월 추가 수입
- **도구 접근성 향상**: 비(非)기술 크리에이터도 고품질 AI 도구 사용 가능
- **생태계 해자**: 축적된 에이전트 자산은 경쟁사가 복제 불가능
- **COSY 수익 다각화**: 마켓플레이스 수수료가 안정적 수익원으로 성장

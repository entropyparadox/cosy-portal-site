# Agent Builder

> **"코딩 없이 나만의 AI 에이전트를 만든다 — COSY의 가장 강력한 차별화."**

---

## 왜 에이전트 빌더인가

크리에이터에게 AI의 힘을 주되, 엔지니어가 될 필요는 없어야 합니다. Agent Builder는 **노코드(No-code) AI 에이전트 생성 플랫폼**으로, 크리에이터가 COSY의 데이터베이스(매출, 크루, 상품, 정산)에 직접 접근하는 에이전트를 만들 수 있게 합니다.

::: warning 핵심 차별화 포인트
Agent Builder는 COSY Portal의 **가장 중요한 차별화 요소**입니다. GPT Store, Zapier, Dify 등은 범용 도구이지만, COSY Agent Builder는 **크리에이터 비즈니스 데이터에 직접 연결**됩니다. 이것은 그 어떤 플랫폼도 제공하지 않는 고유한 가치입니다.
:::

## 프리빌트 템플릿 (Prebuilt Templates)

처음부터 만들 필요가 없습니다. 검증된 템플릿에서 시작하세요.

| 템플릿 | 설명 | 연결 데이터 |
|--------|------|-----------|
| 매출 분석 에이전트 | 일일/주간/월간 매출을 분석하고 인사이트 리포트 생성 | 매출 DB, 상품 DB |
| 콘텐츠 기획 에이전트 | 트렌드 모니터링 + 콘텐츠 캘린더 자동 생성 | SNS 메트릭, 상품 DB |
| 크루 관리 에이전트 | 크루원 성과 추적, 업무 자동 배분, 리마인더 | 크루 DB, 활동 로그 |
| 고객 응대 에이전트 | FAQ 자동 응답, VIP 감지, 이탈 예측 알림 | 고객 DB, 주문 DB |
| 마케팅 자동화 에이전트 | 캠페인 성과 추적, A/B 테스트 결과 요약 | 매출 DB, 광고 메트릭 |

::: info 템플릿은 시작점일 뿐
모든 템플릿은 크리에이터가 자유롭게 수정할 수 있습니다. 트리거 조건 변경, 데이터 소스 추가, 액션 커스터마이징 모두 가능합니다.
:::

## 에이전트 생성 플로우 (Agent Creation Flow)

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐    ┌─────────┐
│  템플릿 선택  │ →  │  데이터 연결  │ →  │  프롬프트 설정 │ →  │  테스트  │ →  │  배포   │
│             │    │             │    │             │    │         │    │         │
│ 프리빌트 or  │    │ COSY DB +   │    │ AI 동작 방식  │    │ 샌드박스 │    │ 라이브   │
│ 빈 캔버스    │    │ 외부 API     │    │ 세부 조정     │    │ 환경 검증│    │ 활성화   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────┘    └─────────┘
```

### 1단계: 템플릿 선택

- 프리빌트 템플릿 중 하나를 선택하거나, 빈 캔버스에서 시작
- 각 템플릿은 트리거, 데이터 소스, 액션이 미리 설정되어 있음

### 2단계: 데이터 연결

- COSY 내부 데이터: 매출, 크루, 상품, 정산, 고객 데이터
- 외부 API 연동: YouTube Analytics, Instagram Insights, Shopify 등
- 권한 설정: 읽기 전용 / 읽기+쓰기 / 관리자 수준

### 3단계: 프롬프트 설정

- 에이전트의 역할과 톤을 자연어로 정의
- 응답 형식 지정 (리포트, 알림, 대화 등)
- 판단 기준 설정 (예: "매출이 전일 대비 20% 이상 하락하면 경고")

### 4단계: 테스트

- 샌드박스 환경에서 실제 데이터로 시뮬레이션
- 에지 케이스(Edge Case) 자동 검증
- 응답 품질 확인 및 프롬프트 미세 조정

### 5단계: 배포

- 원클릭 라이브 배포
- 마켓플레이스 등록 옵션 (선택)
- 사용량 모니터링 대시보드 자동 생성

## 에이전트의 4대 구성 요소

| 구성 요소 | 설명 | 예시 |
|----------|------|------|
| 트리거 (Trigger) | 에이전트가 작동하는 조건 | 스케줄, 이벤트, 사용자 호출 |
| 데이터 소스 (Data Source) | 에이전트가 참조하는 정보 | COSY DB, 외부 API, 파일 |
| AI 모델 (AI Model) | 판단/분석에 사용하는 모델 | 텍스트 분석, 예측, 생성 |
| 액션 (Action) | 에이전트가 수행하는 행동 | 리포트 생성, 알림, 메시지 |

## 경쟁 플랫폼 비교

| 기준 | GPT Store | Zapier | Dify | COSY Agent Builder |
|------|-----------|--------|------|--------------------|
| 노코드 에이전트 생성 | O | 부분적 | O | O |
| 크리에이터 비즈니스 데이터 접근 | X | X | X | **O (핵심)** |
| 프리빌트 크리에이터 템플릿 | X | X | X | **O** |
| 마켓플레이스 판매 | O (범용) | O (연동) | X | **O (크리에이터 특화)** |
| 매출/크루/정산 DB 직접 연결 | X | X | X | **O** |
| 크리에이터 도메인 이해 | X | X | X | **O** |

::: tip COSY만의 진짜 해자
GPT Store에서 "매출 분석 GPT"를 만들 수는 있지만, **내 COSY 매출 데이터에 직접 접근하는 에이전트**는 COSY에서만 만들 수 있습니다. 데이터와 도구가 같은 생태계 안에 있다는 것, 이것이 본질적 차이입니다.
:::

## 기대 효과

- **크리에이터 시간 절약**: 반복 작업 자동화로 주당 10-15시간 절감
- **의사결정 품질 향상**: 데이터 기반 인사이트 자동 제공
- **새로운 수익원**: 에이전트를 마켓플레이스에서 판매하여 추가 수입
- **플랫폼 락인(Lock-in)**: COSY 데이터에 연결된 에이전트는 다른 플랫폼으로 이동 불가

# ② 소속감 — Belonging

> "당신은 고객이 아닙니다. 당신은 COSY 시민입니다."

---

## 왜 소속감인가

크리에이터는 본질적으로 **외로운 직업**입니다. 1인 기업가이자, 콘텐츠 제작자이자, 마케터이자, CS 담당자입니다. 어디에도 소속되지 않은 채 혼자 모든 것을 해결해야 합니다.

기존 플랫폼은 크리에이터를 "유저"로 취급합니다. 구독료를 내는 고객, 수수료를 내는 판매자, 광고 수익을 나누는 파트너 — 어디에도 **"우리 사람"** 이라는 감각은 없습니다.

COSY는 크리에이터에게 **정체성**을 부여합니다. 대학교가 학생에게 학생증과 이메일과 동문 네트워크를 주듯, COSY는 크리에이터에게 소속의 증거를 줍니다.

::: tip 핵심 통찰
기능은 복제할 수 있지만, 소속감은 복제할 수 없습니다. 사람은 더 좋은 도구로 옮기지만, 자신이 속한 커뮤니티를 쉽게 떠나지 않습니다.
:::

## 주요 기능

### @cosy.creator 공식 이메일

COSY에 가입한 크리에이터는 `이름@cosy.creator` 형식의 공식 이메일을 부여받습니다.

| 기능 | 설명 |
|------|------|
| 공식 이메일 주소 | `yourname@cosy.creator` 형식 |
| 비즈니스 명함 효과 | 브랜드/파트너와 소통 시 신뢰도 상승 |
| COSY 메일 클라이언트 연동 | 포털 내에서 직접 이메일 송수신 |
| 자동 서명 | COSY 인증 마크 + 프로필 링크 포함 |

::: info 왜 이메일인가
이메일은 디지털 세계에서 가장 보편적인 **신원 증명**입니다. 회사에 입사하면 회사 이메일을 받듯, COSY에 합류하면 COSY 이메일을 받습니다. 이것만으로 "나는 COSY 크리에이터다"라는 정체성이 형성됩니다.
:::

### 크리에이터 인증 마크

트위터(X)의 파란 체크, 인스타그램의 인증 마크처럼 — COSY는 자체 인증 시스템을 운영합니다.

- **✓ Verified Creator**: 본인 인증 완료 크리에이터
- **★ Pro Creator**: 일정 활동량 및 매출 기준 달성
- **◆ Partner Creator**: COSY 공식 파트너십 체결

인증 마크는 COSY 내부뿐 아니라 외부 임베드 위젯, 프로필 페이지에서도 표시됩니다.

### 공식 프로필 페이지

모든 크리에이터에게 `cosy.creator/yourname` 형식의 공개 프로필 페이지가 제공됩니다.

- 포트폴리오 갤러리
- 활동 이력 및 실적 요약
- 크루 소개 및 팀 구성
- 협업 문의 연결
- SNS 링크 통합

### 등급별 배지 시스템

활동량, 기여도, 매출에 따라 크리에이터 등급이 자동 산정됩니다.

| 등급 | 조건 | 혜택 |
|------|------|------|
| Seed | 가입 즉시 | 기본 기능 접근 |
| Sprout | 첫 매출 발생 또는 크루 1명 이상 | AI 에이전트 3개 사용 |
| Bloom | 월 매출 100만 원 이상 | 프리미엄 템플릿 접근, 마켓플레이스 판매 |
| Forest | 월 매출 500만 원 이상 + 크루 5명 이상 | 전용 서포트, 파트너 매칭 우선권 |
| Cosmos | COSY 선정 Top Creator | 공식 앰배서더, 오프라인 이벤트 초청 |

::: tip 게이미피케이션이 아닙니다
배지 시스템은 "재미를 위한 점수"가 아닙니다. 크리에이터의 **성장 여정을 시각화**하고, 각 단계에서 실질적인 혜택을 제공하는 **경력 사다리**입니다.
:::

## 대학 모델과의 유사성

| 대학교 | COSY |
|--------|------|
| 학생증 | 크리에이터 인증 마크 |
| 학교 이메일 (@university.edu) | @cosy.creator 이메일 |
| 동문 네트워크 | 크리에이터 커뮤니티 |
| 학위/졸업장 | 등급별 배지 |
| 캠퍼스 시설 | COSY 플랫폼 기능 |
| 총학생회 | 크리에이터 자치 거버넌스 |

## 소속감이 만드는 락인 효과

```
가입 → 이메일/프로필 생성 → 인증 마크 획득 → 등급 상승 → 명함에 COSY 크리에이터 표기
→ 외부에서 "COSY 크리에이터"로 인식 → 떠나면 정체성 상실 → 이탈 불가
```

소속감은 COSY의 **감정적 해자(Emotional Moat)** 입니다. 기능은 하루면 복제할 수 있지만, "나는 COSY 크리에이터다"라는 정체성은 그 어떤 경쟁사도 빼앗을 수 없습니다.

# ④ 인프라 — Infrastructure

> "도구를 쓰는 것을 넘어, 도구를 만드는 크리에이터."

---

## 왜 인프라인가

일상화는 매일 접속하게 만들고, 소속감은 떠나지 못하게 만들고, 솔루션은 밖으로 나갈 이유를 없앱니다. 하지만 이것만으로는 **근본적인 차별화**가 부족합니다. 경쟁사도 결국 비슷한 기능을 만들 수 있기 때문입니다.

인프라 축은 다릅니다. 크리에이터가 자신만의 **AI 에이전트를 만들고, 대시보드를 구성하고, 이를 마켓플레이스에서 판매**할 수 있는 생태계입니다. 이것은 그 어떤 크리에이터 플랫폼도 제공하지 않는 COSY만의 핵심 차별화 요소입니다.

::: tip 핵심 통찰
GPT Store가 "누구나 AI 앱을 만들 수 있는 세상"을 열었다면, COSY 인프라는 "크리에이터가 크리에이터를 위한 AI 도구를 만들고 거래하는 세상"을 엽니다.
:::

## 주요 기능

### 노코드 AI 에이전트 빌더

코딩 지식 없이도 자신만의 AI 에이전트를 만들 수 있는 빌더입니다.

| 구성 요소 | 설명 | 예시 |
|----------|------|------|
| 트리거 | 에이전트가 작동하는 조건 | "매출이 전일 대비 20% 하락하면" |
| 데이터 소스 | 에이전트가 참조하는 정보 | 매출 데이터, 크루 활동, SNS 지표 |
| 액션 | 에이전트가 수행하는 행동 | 리포트 생성, 알림 전송, 메시지 발송 |
| AI 모델 | 판단/분석에 사용하는 모델 | 텍스트 분석, 이미지 생성, 데이터 예측 |

::: info 예시: "매출 분석 에이전트"
**트리거**: 매일 오전 9시
**데이터 소스**: COSY Store 매출 + Google Analytics
**액션**: 전일 매출 분석 리포트 생성 → 크루 채팅방에 자동 공유
**AI 모델**: 이상 탐지 + 자연어 요약
:::

### 프리빌트 템플릿

처음부터 만들 필요 없습니다. COSY가 제공하는 검증된 템플릿으로 시작하세요.

| 카테고리 | 템플릿 예시 |
|---------|-----------|
| 매출 분석 | 일일 매출 리포트, 상품별 성과 분석, 재구매율 추적 |
| 콘텐츠 기획 | 트렌드 모니터링, 콘텐츠 캘린더 자동 생성, 해시태그 추천 |
| 크루 관리 | 크루원 성과 대시보드, 업무 자동 배분, 출석 관리 |
| 고객 관리 | VIP 고객 자동 감지, 이탈 예측, 자동 리텐션 메시지 |
| 마케팅 | 캠페인 성과 추적, A/B 테스트 자동화, ROI 분석 |

### 대시보드 빌더

데이터를 시각화하는 나만의 대시보드를 드래그 앤 드롭으로 구성합니다.

- **위젯 라이브러리**: 차트, 표, KPI 카드, 타임라인 등 50+ 위젯
- **데이터 바인딩**: COSY 내부 데이터 + 외부 API 연결
- **실시간 업데이트**: 웹소켓 기반 라이브 데이터 반영
- **공유 및 임베드**: 크루원에게 공유하거나 외부 사이트에 임베드

### 마켓플레이스

크리에이터가 만든 에이전트와 대시보드를 다른 크리에이터에게 판매하거나, 필요한 도구를 구매할 수 있는 생태계입니다.

| 판매자 | 구매자 |
|--------|--------|
| 자신이 만든 에이전트 등록 | 검증된 에이전트 탐색 및 구매 |
| 가격 설정 (무료/유료/구독) | 리뷰 및 평점 확인 |
| 수익 정산 (COSY 수수료 20%) | 원클릭 설치 및 커스터마이징 |
| 업데이트 및 지원 제공 | 사용 데이터 기반 추천 |

::: tip 왜 아무도 안 하는가
크리에이터 특화 AI 인프라를 만들려면 세 가지가 필요합니다: (1) 크리에이터의 데이터 (일상화/솔루션에서 확보), (2) 크리에이터의 신뢰 (소속감에서 확보), (3) 크리에이터 간 거래 생태계 (마켓플레이스). 세 가지를 동시에 갖춘 플랫폼이 없기 때문에 아무도 못하는 것입니다.
:::

## 네트워크 효과

인프라 축의 가장 강력한 특성은 **네트워크 효과**입니다.

```
크리에이터 A가 에이전트 제작 → 마켓플레이스에 등록
→ 크리에이터 B, C, D가 구매 → A에게 수익 발생
→ A가 더 좋은 에이전트 제작 → 마켓플레이스 품질 향상
→ 더 많은 크리에이터 유입 → 더 많은 에이전트 생산
```

이 선순환이 시작되면, 경쟁사가 동일한 기능을 만들어도 **이미 축적된 에이전트 생태계**를 따라잡을 수 없습니다. 이것이 진정한 해자(Moat)입니다.

| 수익원 | 설명 | 예상 비중 |
|--------|------|----------|
| 마켓플레이스 수수료 | 에이전트/대시보드 거래 수수료 20% | 40% |
| 프리미엄 빌더 구독 | 고급 AI 모델, 무제한 에이전트 등 | 35% |
| 엔터프라이즈 라이선스 | MCN/에이전시 대량 이용 | 25% |

인프라는 COSY의 **수익 엔진**이자 **경쟁 해자**입니다. 다른 4개 축이 크리에이터를 데려오고 붙잡는다면, 인프라는 COSY를 **대체 불가능한 생태계**로 만듭니다.

# ① 일상화 — Dailyness

> "크리에이터가 아침에 눈을 뜨면 가장 먼저 여는 화면, 그것이 COSY입니다."

---

## 왜 일상화인가

대부분의 크리에이터 도구는 **"필요할 때만 접속"** 하는 유틸리티입니다. Shopify는 주문이 들어올 때, Mailchimp는 뉴스레터를 보낼 때, 네이버 스마트스토어는 정산일에만 열어봅니다. 이런 도구는 크리에이터의 일상에 녹아들지 못합니다.

COSY는 다릅니다. 크리에이터의 **운영체제(OS)** 를 지향합니다. 매일 여는 첫 화면에서 오늘 해야 할 일, 어제의 성과, 지금 벌어지고 있는 일을 한눈에 보여줍니다.

::: tip 핵심 통찰
습관이 만들어지면 이탈이 사라집니다. 매일 접속하는 서비스를 떠나는 것은, 가끔 접속하는 도구를 교체하는 것보다 100배 어렵습니다.
:::

---

## 주요 기능

### 홈 대시보드

크리에이터가 로그인하면 가장 먼저 보는 화면입니다. 한눈에 현황을 파악할 수 있도록 핵심 지표를 배치합니다.

| 위젯 | 표시 정보 | 업데이트 주기 |
|------|----------|-------------|
| 매출 요약 | 오늘/이번 주/이번 달 매출, 전일 대비 증감 | 실시간 |
| 크루 현황 | 활동 중인 크루원 수, 최근 활동 요약 | 5분 |
| AI 에이전트 현황 | 가동 중인 에이전트 수, 최근 실행 결과 | 실시간 |
| 콘텐츠 성과 | 조회수, 참여율, 트렌딩 콘텐츠 | 1시간 |
| 알림 요약 | 미확인 알림 수, 긴급 항목 하이라이트 | 실시간 |

### 실시간 알림 센터

흩어진 알림을 하나로 모읍니다. 이메일, DM, 주문, 크루 활동, 에이전트 실행 결과까지 — 모든 이벤트가 COSY 알림 센터로 수렴됩니다.

- **긴급 알림**: 결제 실패, 재고 소진, 크루원 이탈 등 즉각 조치가 필요한 항목
- **일반 알림**: 새 팔로워, 댓글, 주문 접수 등 일상 이벤트
- **요약 알림**: AI가 하루 활동을 요약하여 매일 아침 제공

### 개인화 피드

크리에이터의 관심사와 활동 패턴을 학습하여 맞춤형 콘텐츠를 제공합니다.

- 같은 분야 크리에이터의 성과/인사이트
- 관련 트렌드 및 시장 변화
- 추천 에이전트 및 템플릿
- 커뮤니티 인기 게시글

### 할 일 관리 & 캘린더

크리에이터의 업무 흐름을 COSY 안에서 관리합니다. 외부 캘린더(Google, Apple)와 양방향 동기화되어 별도 도구가 필요하지 않습니다.

::: info 자동 할 일 생성
AI 에이전트가 매출 데이터, 크루 활동, 콘텐츠 성과를 분석하여 "오늘 해야 할 일"을 자동으로 제안합니다. 크리에이터는 승인만 하면 됩니다.
:::

## 경쟁사 비교

| 항목 | 기존 도구 (Shopify, Notion 등) | COSY |
|------|-------------------------------|------|
| 접속 빈도 | 필요할 때만 (주 2-3회) | 매일 (목표: 일 1회 이상) |
| 첫 화면 | 기능 메뉴 또는 빈 캔버스 | 오늘의 현황 대시보드 |
| 알림 | 이메일로 분산 전송 | 통합 알림 센터 |
| 할 일 관리 | 별도 도구 필요 (Notion, Todoist) | 내장 + AI 자동 제안 |
| 개인화 | 없음 또는 기본 수준 | 활동 기반 학습 피드 |

## 성공 지표

| 지표 | 목표 |
|------|------|
| DAU / MAU 비율 | 40% 이상 (카카오톡 수준) |
| 평균 일일 체류 시간 | 15분 이상 |
| 첫 화면 이탈률 | 20% 이하 |
| 알림 확인율 | 70% 이상 |

::: tip 벤치마크
Instagram의 DAU/MAU 비율은 약 60%, Slack은 약 50%입니다. COSY가 크리에이터의 "매일 여는 앱"이 되려면, 최소 40% 이상의 DAU/MAU 비율이 필요합니다.
:::

## 일상화가 만드는 선순환

```
매일 접속 → 데이터 축적 → AI 개인화 향상 → 더 유용한 경험 → 더 자주 접속
```

일상화는 단순히 "자주 들어오게 만드는 것"이 아닙니다. 크리에이터가 COSY 없이는 하루를 시작할 수 없는 상태, **운영체제 수준의 의존성**을 만드는 것이 목표입니다.

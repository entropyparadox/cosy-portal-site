# 법인 구조 옵션

> **"시작은 가볍게, 성장은 단단하게 — 단계적 전환 전략."**

---

## 왜 법인 구조가 중요한가

EP와 glowuprizz의 협업은 단순한 프로젝트 외주가 아닙니다. COSY Portal이라는 **새로운 사업**을 함께 만드는 것이기 때문에, 법인 구조는 수익 배분, 의사결정 권한, 리스크 분담의 기반이 됩니다.

::: info 의사결정 기준
법인 구조는 **"지금 가장 적합한 형태"**가 아니라 **"성장 과정에서 가장 유연한 형태"**를 기준으로 선택해야 합니다.
:::

---

## Option A: 단일 법인 (JV 회사 설립)

EP와 glowuprizz가 공동 출자하여 새로운 JV(Joint Venture) 법인을 설립합니다.

### 구조

```
EP (50%)  ──┐
            ├──→  COSY Portal Inc. (JV 법인)
glowuprizz ─┘
(50%)
```

### 장단점

| 구분 | 내용 |
|------|------|
| 장점 | 의사결정 구조 명확, 수익/비용 투명, 외부 투자 유치 용이 |
| 단점 | 법인 설립 비용/시간, 유연성 낮음, 해산 시 복잡 |
| 리스크 | 초기 불확실성이 높은 상황에서 과도한 커밋먼트 |
| 적합 시점 | 사업 모델이 검증된 후 (Series A 이후) |

---

## Option B: 이중 법인 (각자 법인, 계약 기반)

EP와 glowuprizz가 각자의 법인을 유지하면서, 사업 계약으로 협업합니다.

### 구조

```
EP (자사 법인)         glowuprizz (자사 법인)
    │                       │
    │   ┌─────────────┐     │
    └──→│  사업 계약    │←────┘
        │  (MOU/JVA)   │
        └──────┬──────┘
               │
        COSY Portal
        (프로젝트)
```

### 장단점

| 구분 | 내용 |
|------|------|
| 장점 | 각자 독립 경영, 해산 간단, 기존 사업 영향 최소 |
| 단점 | 의사결정 충돌 시 해결 어려움, IP 소유권 분쟁 가능, 투자 유치 복잡 |
| 리스크 | 한쪽이 이탈할 경우 프로젝트 지속성 위험 |
| 적합 시점 | 아이디어 검증 단계, 초기 실험 |

---

## Option C: 단계적 전환 (추천)

처음에는 계약 기반으로 시작하고, 성과가 검증되면 JV 법인으로 전환합니다.

### 구조

```
Stage 1 (Q3-Q4 2026)          Stage 2 (2027+)
────────────────────          ──────────────────

EP ──┐                        EP (50%) ──┐
     ├── 사업 계약 (MOU/JVA)              ├──→ COSY Portal Inc.
GUR ─┘                        GUR (50%) ─┘

계약 기반 협업                  법인 전환 (조건 충족 시)
```

### 단계별 전환 조건

| 단계 | 기간 | 구조 | 전환 조건 |
|------|------|------|----------|
| Stage 1 | Q3-Q4 2026 | 사업 계약 (MOU) | - |
| Stage 1.5 | Q1-Q2 2027 | JV 계약 (JVA) | MAU 1,000+ 달성 |
| Stage 2 | Q3 2027+ | JV 법인 설립 | 월 매출 5,000만원+ 또는 투자 유치 확정 |

### 장단점

| 구분 | 내용 |
|------|------|
| 장점 | 리스크 최소화, 검증 후 커밋, 유연한 전환, 단계별 투자 |
| 단점 | 초기에 법적 구속력 약함, IP 관리 주의 필요 |
| 리스크 | 전환 시점 합의 필요 (미리 계약서에 명시) |
| 적합 시점 | **지금 (현재 상황에 최적)** |

::: tip 왜 Option C인가
1. COSY Portal은 아직 **제품 검증(PMF) 이전 단계**입니다
2. JV 법인 설립은 최소 2-3개월 + 수백만원의 비용이 소요됩니다
3. 계약 기반으로 빠르게 시작하고, 성과로 증명한 뒤 법인화하는 것이 합리적입니다
4. 전환 조건을 미리 합의해두면, 양사 모두 예측 가능한 구조가 됩니다
:::

## 3가지 옵션 비교 요약

| 기준 | Option A (단일 법인) | Option B (이중 법인) | Option C (단계적 전환) |
|------|---------------------|---------------------|----------------------|
| 초기 비용 | 높음 | 낮음 | 낮음 |
| 의사결정 명확성 | 매우 높음 | 낮음 | 중간 → 높음 |
| 유연성 | 낮음 | 높음 | 높음 → 중간 |
| 리스크 | 높음 | 중간 | **낮음** |
| 투자 유치 | 용이 | 복잡 | 단계적 용이 |
| 이탈 용이성 | 어려움 | 쉬움 | 단계별 조정 |
| **추천도** | - | - | **추천** |

---

## 핵심 계약 조항 (Stage 1)

Option C로 진행 시, Stage 1 MOU에 반드시 포함해야 할 조항입니다.

| 조항 | 내용 |
|------|------|
| IP 소유권 | Portal IP는 공동 소유, Platform IP는 glowuprizz 단독 |
| 전환 조건 | MAU/매출 기준 명시, 전환 시 지분율 산정 방식 |
| 비경쟁 | 유사 서비스 단독 출시 금지 (계약 기간 중) |
| 이탈 조건 | 3개월 사전 통보, 데이터/코드 정리 기간 보장 |
| 분쟁 해결 | 중재 기관 지정 (대한상사중재원 등) |

::: warning 법률 검토 필수
이 문서는 전략적 방향성을 제시하는 것이며, 실제 계약서 작성 시 반드시 법률 전문가의 검토를 받아야 합니다.
:::

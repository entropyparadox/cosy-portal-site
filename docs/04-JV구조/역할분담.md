# EP x glowuprizz 역할 분담

> **"철학과 기술의 EP, 운영과 관계의 glowuprizz — 각자의 강점이 만나 시너지를 만든다."**

---

## 역할 분담 원칙

두 회사의 강점이 명확히 다르기 때문에, 역할 분담도 명확해야 합니다. **겹치는 영역을 최소화**하고, **각자가 잘하는 것에 집중**하는 구조입니다.

::: info 핵심 구분 기준
- **Portal (포털)** = 크리에이터가 보고 쓰는 화면 → **EP 주도**
- **Platform (플랫폼)** = 데이터가 흐르고 비즈니스가 돌아가는 백엔드 → **glowuprizz 주도**
:::

---

## EP (Entropy Paradox) 주도 영역

EP는 Portal의 **"보이는 것"과 "생각하는 것"**을 담당합니다.

| 영역 | 상세 내용 | 산출물 |
|------|----------|--------|
| 브랜딩 | COSY Portal의 브랜드 아이덴티티, 네이밍, 비주얼 랭귀지 | 브랜드 가이드라인, CI/VI |
| 철학 | "크리에이터의 운영체제" 비전, 5대 축 설계, 로드맵 | 비전 문서, 전략 기획 |
| AI 인프라 | Agent Builder, Dashboard Builder, Marketplace 설계 및 개발 | 프론트엔드 + AI 레이어 |
| UI/UX 디자인 | Portal 전체 화면 설계, 인터랙션 디자인, 디자인 시스템 | Figma 디자인, 컴포넌트 |

::: tip EP의 강점
- AI 에이전트 아키텍처 설계 및 구현 경험
- 브랜딩과 제품 철학을 통합하는 역량
- UI/UX 디자인 시스템 구축 역량
:::

---

## glowuprizz 주도 영역

glowuprizz는 Platform의 **"돌아가는 것"과 "연결되는 것"**을 담당합니다.

| 영역 | 상세 내용 | 산출물 |
|------|----------|--------|
| 플랫폼 운영 | 기존 COSY Platform 운영, 서비스 안정성, SLA 관리 | 운영 대시보드, SLA 리포트 |
| 크리에이터 관계 관리 | 크리에이터 온보딩, CS, 커뮤니티 관리 | 온보딩 가이드, CS 매뉴얼 |
| 커머스/정산 | 상품 관리, 주문 처리, 정산 시스템, 세금 처리 | 정산 시스템, API |
| DB/API | 매출/크루/상품/정산/고객 데이터베이스 및 API 제공 | REST API, 데이터 파이프라인 |
| 크루 시스템 | 크루 생성, 역할 관리, 활동 추적 시스템 | 크루 관리 시스템 |

::: tip glowuprizz의 강점
- 크리에이터 커머스 운영 노하우
- 정산/세금 처리 시스템 보유
- 크리에이터 네트워크 및 관계 자산
:::

## 공유 영역 (Shared Ownership)

양사가 함께 의사결정하고 실행하는 영역입니다.

| 영역 | EP 역할 | glowuprizz 역할 |
|------|---------|-----------------|
| 마케팅 | 브랜드 마케팅, 콘텐츠 마케팅 | 크리에이터 대상 마케팅, 바이럴 |
| 사업 개발 | 기술 파트너십, AI 벤더 관계 | 크리에이터 파트너십, MCN 관계 |
| 전략적 의사결정 | 제품 로드맵, 기술 방향 | 시장 전략, 크리에이터 니즈 |

## 커뮤니케이션 구조

| 채널 | 주기 | 참석자 | 목적 |
|------|------|--------|------|
| 주간 싱크 | 매주 1회 | 양사 PM + 리드 | 진행 상황, 이슈, 우선순위 조정 |
| 월간 리뷰 | 매월 1회 | 양사 경영진 | KPI 검토, 전략 방향, 리소스 배분 |
| 분기 전략 | 분기 1회 | 양사 대표 | 로드맵 조정, 투자/확장 의사결정 |
| 일일 슬랙 | 상시 | 양사 실무자 | 실시간 이슈, 기술 협의 |

::: warning 의사결정 교착 방지
양사 의견이 충돌할 경우, **"사용자(크리에이터)에게 더 나은 선택"**을 기준으로 판단합니다. 기술적 우아함이나 사업적 편의보다 크리에이터 경험을 우선합니다.
:::

## 기대 효과

- **속도**: 각자의 전문 영역에 집중하여 개발/운영 속도 극대화
- **품질**: 강점 영역의 전문성이 결과물의 품질을 보장
- **리스크 분산**: 한 회사에 의존하지 않는 구조로 사업 리스크 분산
- **확장성**: 역할이 명확하므로 인원 확대 시에도 혼선 최소화

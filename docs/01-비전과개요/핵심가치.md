# 핵심 가치

> COSY Portal이 추구하는 근본적인 가치와 원칙

---

## 3대 핵심 가치

### 1. 🏠 크리에이터 우선 (Creator-First)

모든 의사결정에서 크리에이터의 이익이 최우선입니다.

- 크리에이터는 "고객"이 아니라 **생태계의 구성원**
- 크리에이터의 데이터는 크리에이터의 것
- 크리에이터가 만든 에이전트/대시보드에 대한 **소유권과 수익권** 보장
- 플랫폼 성장의 이익이 크리에이터에게 돌아가는 구조

### 2. 🌐 생태계 사고 (Ecosystem Thinking)

개별 기능이 아닌, 상호 연결된 생태계를 구축합니다.

- 크리에이터가 크리에이터를 돕는 구조 (에이전트 마켓플레이스)
- 사용자가 늘수록 모든 사용자에게 가치가 증가 (네트워크 효과)
- 하나의 플랫폼에서 업무의 전체 사이클을 완결 (통합 경험)
- 크리에이터 간 시너지가 자연스럽게 발생하는 설계

### 3. 🤖 AI 네이티브 (AI-Native)

AI는 부가 기능이 아니라, COSY Portal의 **근간**입니다.

- 모든 크리에이터에게 **개인 AI 비서** 제공
- 크리에이터가 직접 AI 에이전트를 만들 수 있는 **노코드 빌더**
- 에이전트가 COSY 데이터에 직접 접근 → 맞춤형 인사이트
- 에이전트 마켓플레이스를 통한 **에이전트 경제** 형성

## 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **심플한 시작** | 쉽게 시작하고 깊게 성장 | 가입 즉시 홈 대시보드 활성화 |
| **점진적 깊이** | 필요에 따라 기능 발견 | 처음엔 대시보드 → 나중에 에이전트 빌더 |
| **소유와 이동** | 데이터 주권 보장 | 크리에이터 데이터 내보내기 지원 |
| **투명한 경제** | 수수료와 수익 구조 투명 공개 | 에이전트 판매 수익의 80%는 크리에이터 |
| **커뮤니티 기반** | 크리에이터 커뮤니티가 방향 결정 | 기능 제안 → 투표 → 개발 |

## Claude/Anthropic에서 배운 교훈

COSY Portal의 설계 원칙은 Anthropic의 Claude 생태계에서 영감을 받았습니다:

| Claude (개발자) | COSY Portal (크리에이터) |
|----------------|----------------------|
| API + MCP 서버 | COSY API Hub + 에이전트 |
| 개발자 도구 생태계 | 크리에이터 도구 생태계 |
| Custom GPT / Claude Projects | Agent Builder |
| 개발자 커뮤니티 | 크리에이터 커뮤니티 (크루) |
| 사용량 기반 과금 | 캐시 포인트 경제 |

::: tip 차별화 포인트
Claude가 "코드를 모르는 사람도 개발할 수 있게" 만들었듯이,  
COSY Portal은 **"기술을 모르는 크리에이터도 AI 에이전트를 만들 수 있게"** 합니다.
:::

## 경쟁사 공통 약점

COSY Portal이 파고들 수 있는 5가지 구멍:

### 1. "도구"에 머무름
소속감, 정체성 부여 없음. 사용자는 "고객"일 뿐.

### 2. 분산된 경험
이메일은 Mailchimp, 커머스는 Shopify, 커뮤니티는 Discord → **통합 없음**

### 3. AI 에이전트 부재
**어떤 플랫폼도 크리에이터 전용 AI 에이전트 빌더를 제공하지 않음**

### 4. 네트워크 효과 약함
대부분 개인 크리에이터 도구. 크리에이터 간 시너지 구조 없음.

### 5. 데이터 활용 미흡
축적된 데이터를 크리에이터가 직접 활용할 방법 없음.

::: tip COSY의 기회
이 5가지 약점은 정확히 COSY Portal의 5대 축과 대응합니다:
- 도구에 머무름 → **일상화** (매일 사용하는 OS)
- 소속감 없음 → **소속감** (@cosy 이메일, 인증 마크)
- 분산된 경험 → **솔루션** (통합 커뮤니케이션)
- AI 부재 → **인프라** (Agent Builder)
- 데이터 미활용 → **인프라** (COSY API Hub)
:::

## AI 에이전트 빌더 경쟁 환경

| 플랫폼 | 유형 | 타겟 | 크리에이터 적합도 |
|--------|------|------|-----------------|
| GPT Store (OpenAI) | Custom GPT 빌더 | 일반 사용자 | 중 — 범용적, 크리에이터 특화 X |
| Zapier / Make.com | 워크플로우 자동화 | 비즈니스 | 하 — 기술적, 크리에이터 친화 X |
| Bubble / Webflow | 노코드 앱 빌더 | 기업가 | 하 — 학습 곡선 높음 |
| Relevance AI | AI Agent 빌더 | 비즈니스 | 중 — B2B 특화 |
| Dify / Coze | LLM 기반 앱 빌더 | 개발자/비개발자 | 중 — 범용 AI 앱 |
| **COSY Agent Builder** | **크리에이터 특화** | **크리에이터** | **최고 — COSY DB 직접 접근** |

::: warning 핵심 차별점
기존 에이전트 빌더들은 모두 **범용 도구**입니다.  
COSY Agent Builder만이 **크리에이터의 실제 데이터**(매출, 크루, 상품, 정산)에 직접 접근할 수 있습니다.
:::

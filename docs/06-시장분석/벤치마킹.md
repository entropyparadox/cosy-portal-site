## 핵심 성공 요인

### 1. "도구"에서 "환경"으로의 전환

- Notion은 노트앱이 아니라 **"팀의 두뇌"**
- Slack은 채팅앱이 아니라 **"업무의 중심"**
- COSY Portal은 판매도구가 아니라 **"크리에이터의 오피스"**

::: info 핵심 인사이트
사용자가 "OO을 쓴다"가 아니라 **"OO에서 일한다"**고 말하는 순간, 도구는 환경이 됩니다.  
COSY Portal의 목표는 크리에이터가 **"COSY에서 일한다"**고 말하게 만드는 것입니다.
:::

### 2. 사용자 생성 가치 (UGV: User Generated Value)

| 플랫폼 | 사용자 생성 가치 | COSY 적용 |
|--------|----------------|----------|
| Shopify | 앱 스토어 (개발자 → 셀러) | 에이전트 마켓플레이스 |
| Claude | MCP 서버 (커뮤니티 → 생태계) | 크리에이터 → 크리에이터 |
| Figma | 플러그인 (디자이너 → 디자이너) | 대시보드/에이전트 공유 |

### 3. 전환 비용 (Switching Cost) 설계

성공적인 포털은 **4가지 Lock-in**을 복합적으로 구축합니다:

- **데이터 Lock-in**: 축적된 정보가 플랫폼에 종속
- **네트워크 Lock-in**: 관계/팀이 플랫폼에 종속
- **워크플로우 Lock-in**: 자동화/에이전트가 플랫폼에 종속
- **아이덴티티 Lock-in**: 이메일/인증이 플랫폼에 종속 ← **COSY 고유 기회**

::: tip COSY의 독보적 기회
4가지 Lock-in 중 **아이덴티티 Lock-in**은 경쟁사 중 아무도 시도하지 않은 영역입니다.  
@cosy 이메일과 인증 마크는 COSY만의 고유한 해자가 됩니다.
:::

## COSY에 적용할 교훈

1. **첫 5분 경험이 중요** — 가입 즉시 가치를 느끼게 (홈 대시보드)
2. **축적이 가치가 되게** — 쓸수록 떠날 수 없게 (데이터, 에이전트, 관계)
3. **사용자가 가치를 만들게** — 크리에이터가 에이전트를 만들면 생태계 성장
4. **브랜드가 정체성이 되게** — "COSY 크리에이터"가 시장의 신뢰 마크

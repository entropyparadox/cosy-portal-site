# 포지셔닝 맵

> COSY Portal의 시장 내 위치와 차별화 전략

---

## 경쟁 포지셔닝

COSY Portal은 **"높은 소속감 + 생태계 중심"** 사분면에 단독 포지셔닝합니다.

```
                    높은 소속감/정체성
                         │
                    COSY Portal ★
                    (목표 포지션)
                         │
        ─────────────────┼─────────────────
        기능 중심         │         생태계 중심
        (Beacons, Stan)  │         (Shopify, Notion)
                         │
                    낮은 소속감
                    (대부분 경쟁사)
```

## 차별화 축

| 축 | 경쟁사 현황 | COSY 전략 |
|----|-----------|----------|
| **일상화** | 없음 (필요할 때만 접속) | 홈 대시보드 → 매일 첫 화면 |
| **소속감** | 없음 (사용자는 "고객") | @cosy 이메일 + 인증 마크 → "시민" |
| **솔루션** | 분산 (각각 다른 도구) | 통합 메신저 → COSY 안에서 완결 |
| **인프라** | 없음 (AI 에이전트 빌더 0) | Agent Builder + Marketplace → **독보적** |
| **브랜딩** | 약함 (도구에 불과) | "COSY 크리에이터" = 전문가 레이블 |

## 타겟 사용자

### 1차 타겟: 기존 COSY 크리에이터
- glowuprizz 플랫폼의 현재 사용자
- 포털 기능을 점진적으로 경험
- 콜드스타트 문제 해결의 핵심

### 2차 타겟: 성장형 크리에이터
- 월 매출 100만원~1000만원
- 팀(크루) 빌딩 중
- 도구 통합 니즈 높음

### 3차 타겟: 신규 크리에이터
- 크리에이터 시작 단계
- AI 에이전트로 빠른 성장
- COSY 브랜드에 매력 느낌

::: tip Go-to-Market 전략
기존 COSY 사용자를 포털로 자연스럽게 전환 → 성공 사례 축적 → 외부 크리에이터 유입.  
이것이 glowuprizz와의 JV가 핵심인 이유입니다. **콜드스타트 없이 시작**할 수 있습니다.
:::

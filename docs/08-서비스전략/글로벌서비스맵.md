# 글로벌 서비스 맵 — Public Utility Strategy

> "세계 최고 플랫폼들이 쓰는 공식 — 무료로 없어서는 안 될 인프라를 깔고, 그 위에서 돈이 흐르게 만든다."

---

## 프레임워크

Stripe가 **결제**를 인프라로 만들었고, Shopify가 **커머스**를 인프라로 만들었고, Notion이 **워크스페이스**를 인프라로 만들었다면, COSY는 **크리에이터의 전체 비즈니스 운영**을 인프라로 만든다.

COSY Portal의 각 서비스는 3가지 역할 중 하나를 수행합니다:

| 역할 | 목적 | 수익 방식 | 글로벌 벤치마크 |
|------|------|----------|----------------|
| **Magnet** | 유저 유입, 습관화 | 무료 (비용 센터) | Google Maps, Canva Free |
| **Sticky** | 대체 불가 → 이탈 방지 | 프리미엄 전환 | Notion Teams, Slack Pro |
| **Engine** | 직접 수익 창출 | 수수료·구독·라이선스 | Shopify App Store, Stripe Connect |

::: tip 핵심 원칙
Magnet으로 끌어들이고 → Sticky로 떠나지 못하게 하고 → Engine에서 돈이 흐르게 한다. 세 레이어가 모두 있어야 생태계입니다.
:::

## A. Creator Identity Infrastructure

**"크리에이터판 Stripe Atlas"** — Stripe Atlas가 10분 만에 미국 법인 설립을 민주화했듯이, COSY는 크리에이터의 프로페셔널 정체성을 민주화합니다.

### 서비스 목록

| # | 서비스 | 글로벌 벤치마크 | 역할 | 왜 공익적인가 |
|---|--------|---------------|------|-------------|
| 1 | **글로벌 크리에이터 ID** — `@cosy.creator` 이메일 + 인증마크 + 공개 프로필 포트폴리오 | Stripe Atlas + LinkedIn | Magnet | 크리에이터가 "나는 프로다"를 증명할 글로벌 표준이 없음. COSY가 그 여권을 발급 |
| 2 | **크리에이터 신용 스코어** — 매출 이력, 팔로워 성장률, 브랜드 협업 이력 기반 신뢰도 점수 | FICO Score + GitHub Contribution Graph | Sticky | 브랜드가 인플루언서를 고를 때, 크리에이터가 대출받을 때 — 객관적 지표가 없음 |
| 3 | **커스텀 도메인 프로필** — `yourname.cosy.creator` + 임베더블 인증 위젯 | Linktree + Verified Badge | Magnet | 무료 프로필이 명함·SNS 바이오·포트폴리오를 한번에 해결 |
| 4 | **티어 & 배지 시스템** — Seed → Sprout → Bloom → Forest → Cosmos | Google Local Guide Levels + GitHub Stars | Sticky | 소속감과 성취 욕구를 자극하는 게이미피케이션 |

::: info 수익 전환 (Engine)
프리미엄 프로필 (커스텀 디자인, 고급 분석), 브랜드-크리에이터 매칭 수수료, 크리에이터 대출/보험 중개 수수료
:::

## B. Creator Workspace

**"크리에이터판 Notion + Slack + Canva"** — Notion이 무료 워크스페이스로 1억 유저를 모은 뒤 Team/Enterprise로 수익화한 공식.

### 서비스 목록

| # | 서비스 | 글로벌 벤치마크 | 역할 | 왜 공익적인가 |
|---|--------|---------------|------|-------------|
| 5 | **AI 비서 대시보드** — 매출·콘텐츠·크루 현황 한 화면 + 매일 아침 AI 브리핑 | Notion Home + Linear Dashboard | Magnet | 크리에이터가 매일 아침 "오늘 뭐 해야 하지?"를 10초 만에 파악 |
| 6 | **통합 메신저** — 크루 내부 + 고객 1:1 + 브랜드 협업 + AI 자동응답 | Slack + Intercom + Discord 통합 | Sticky | 대화가 3-4개 앱에 흩어지는 문제를 1곳으로 |
| 7 | **COSY Drive** — 에셋 관리 + AI 태깅 + 자동 포맷 변환 + 버전관리 | Google Drive + Dropbox + Canva Asset Manager | Sticky | 크리에이터의 이미지/영상/문서를 AI가 정리해주는 무료 저장소 |
| 8 | **AI 콘텐츠 툴킷** — 썸네일 생성, 캡션 작성, 해시태그 추천, A/B 테스트 | Canva + Copy.ai + Pictory | Magnet | 매번 유료 도구 5개 쓸 필요 없이 COSY 안에서 완결 |
| 9 | **크로스플랫폼 스케줄러** — YouTube + Instagram + TikTok + X 동시 예약 발행 | Buffer + Hootsuite + Later | Magnet | 무료 티어로 모든 SNS 한방에 관리 |
| 10 | **COSY Mail** — `@cosy.creator` 송수신 + 뉴스레터 + AI 자동분류/초안 | Gmail + Mailchimp + Beehiiv | Sticky | 이메일 마케팅까지 통합 |
| 11 | **COSY Meet** — 브라우저 화상회의 + 녹화 + AI 회의록 자동 생성 | Zoom + Google Meet | Magnet | 설치 없는 미팅 + AI가 회의록까지 |

::: tip 교차 서비스 데이터 연결 — 진짜 해자
```
고객 A → 메신저 문의 → 이메일 견적 → Drive 계약서 → Meet 미팅 → Tasks 후속조치
```
이 모든 히스토리가 1곳에서 조회됩니다. Notion은 문서만, Slack은 메시지만, Zoom은 미팅만. 하지만 "크리에이터의 하루 전체를 연결하는 경험"은 오직 COSY에서만 가능합니다.
:::

::: info 수익 전환 (Engine)
Notion 모델 — 무료(개인) → Pro(크루 협업, 용량 확장) → Enterprise(MCN/에이전시). AI 기능 고급 티어 과금.
:::

## C. Creator Finance

**"크리에이터판 Stripe + Mercury + Deel"** — Stripe가 "개발자 7줄 코드로 결제 붙이기"를 무료로 풀어서 글로벌 결제 인프라가 되었듯이.

### 서비스 목록

| # | 서비스 | 글로벌 벤치마크 | 역할 | 왜 공익적인가 |
|---|--------|---------------|------|-------------|
| 12 | **크리에이터 정산 허브** — 멀티 플랫폼 수익 통합 대시보드 (YouTube·Shopify·브랜드딜 수익을 1곳에서) | Mercury + Stripe Dashboard | Magnet | 크리에이터의 돈이 5곳에 흩어져 있는데, 종합 재무 현황을 보여주는 곳이 없음 |
| 13 | **자동 세금 계산 + 증빙 관리** — 국가별 세금 자동 계산, 경비 OCR, 세금 리포트 생성 | TurboTax + Deel | Sticky | 1인 크리에이터의 최대 고통 = 세금. 이걸 무료로 풀면 절대 떠나지 않음 |
| 14 | **인보이스 + 계약서 자동 생성** — 브랜드 협업 계약서, 크루 계약서 템플릿, 전자서명 | DocuSign + HoneyBook + Bonsai | Magnet | 매번 변호사 쓸 수 없는 크리에이터에게 무료 법률 템플릿 + AI 리뷰 |
| 15 | **크로스보더 결제** — 글로벌 팬 직접 결제 수신, 다중 통화, 자동 환전 | Stripe Connect + Wise + Payoneer | Engine | 해외 팬이 한국 크리에이터에게 직접 결제할 수 있는 인프라 |

::: warning 왜 금융이 해자가 되는가
세금 데이터, 거래 히스토리, 정산 기록은 시간이 지날수록 누적됩니다. 3년치 재무 데이터를 다른 플랫폼으로 옮기는 크리에이터는 없습니다. **금융 데이터 = 시간의 함수 = 복제 불가능.**
:::

::: info 수익 전환 (Engine)
Stripe 모델 — 거래 수수료 2-3%, 프리미엄 금융 서비스 (선정산, 크리에이터 대출, 보험 중개), 엔터프라이즈 정산 서비스
:::

### 서비스 목록

| # | 서비스 | 글로벌 벤치마크 | 역할 | 왜 공익적인가 |
|---|--------|---------------|------|-------------|
| 16 | **통합 애널리틱스** — YouTube + Insta + TikTok + Shopify + 자사몰 데이터를 한 화면에 | Google Analytics + Amplitude + Social Blade 통합 | Magnet | 각 플랫폼 분석이 따로 놀아서 "전체 그림"을 못 보는 문제 해결 |
| 17 | **AI 트렌드 리포트** — 니치 시장 트렌드 자동 분석, 경쟁자 모니터링, 콘텐츠 기회 알림 | Exploding Topics + SparkToro + Google Trends | Sticky | 트렌드를 쫓는 게 크리에이터의 생존. 자동화해주면 떠날 수 없음 |
| 18 | **AI 대시보드 빌더** — 드래그앤드롭 비즈니스 대시보드, 50+ 위젯, 실시간 데이터 | Looker Studio + Retool + Metabase | Sticky | "내 비즈니스의 숫자를 한눈에" — 무료로 주고 데이터 락인 |
| 19 | **팬/고객 인사이트** — 구매 패턴, LTV 예측, 이탈 예측, VIP 자동 식별 | Mixpanel + HubSpot CRM | Engine | 크리에이터에게 "당신의 Top 100 팬이 누구인지" 알려주는 무료 CRM |

::: info 수익 전환 (Engine)
프리미엄 분석 (고급 AI 예측, 실시간 알림, 팀 공유), 데이터 API 과금 (1K/일 무료 → Enterprise 무제한)
:::

## E. Creator AI Agent Economy

**"크리에이터판 Shopify App Store + GPT Store"** — COSY의 핵심 차별화. 다른 어디에도 없는 것.

### 서비스 목록

| # | 서비스 | 글로벌 벤치마크 | 역할 | 왜 게임체인저인가 |
|---|--------|---------------|------|-----------------|
| 20 | **노코드 AI 에이전트 빌더** — 크리에이터의 실제 비즈니스 DB에 연결된 AI 에이전트 생성 | GPT Store + Zapier + Dify | Engine | GPT Store 에이전트는 범용. COSY 에이전트는 "내 매출, 내 크루, 내 고객" 데이터로 작동 |
| 21 | **에이전트 마켓플레이스** — 크리에이터가 만든 에이전트를 다른 크리에이터에게 판매 (80/20 분배) | Shopify App Store + Figma Community | Engine | 크리에이터가 소비자이자 생산자. 양면 시장 = 네트워크 효과 |
| 22 | **에이전트 번들 + 템플릿** — 산업별 올인원 패키지 (뷰티, 패션, 교육, F&B 등) | Shopify Themes + Webflow Templates | Magnet | "뷰티 크리에이터 스타터팩" 설치하면 5분 만에 비즈니스 자동화 완성 |
| 23 | **COSY API Hub** — 내부 6개 도메인 API + 외부 6개 플랫폼 연동, 개발자 포털 | Stripe API + Twilio + Shopify API | Engine | 외부 개발자/회사도 COSY 생태계 위에 서비스를 구축할 수 있는 개방형 인프라 |

::: warning 이것이 왜 유일무이한가
GPT Store는 범용 AI. Zapier는 자동화만. Shopify App Store는 커머스만. **비즈니스 데이터(매출·크루·고객·정산)에 직접 연결된 AI 에이전트 마켓플레이스**는 COSY 외에 존재하지 않습니다. 이 에이전트들은 COSY 데이터에 묶여 있으므로 **다른 플랫폼으로 이전 불가** — 이것이 궁극의 해자입니다.
:::

::: info 수익 전환 (Engine)
마켓플레이스 수수료 20% (크리에이터 80% — Apple 70%보다 관대), 프리미엄 AI 모델 구독, 엔터프라이즈 라이선스
:::

## F. Blue Ocean — 아직 세상에 없는 서비스

현존하는 글로벌 플랫폼 중 어디도 제공하지 않지만, 크리에이터에게 절실한 서비스.

| # | 서비스 | 왜 아직 없나 | COSY가 하면 | 역할 |
|---|--------|------------|-----------|------|
| 24 | **크리에이터 신용평가 시스템** | 금융권이 크리에이터 비즈니스를 이해 못함 | COSY 데이터 기반 신용평가 → 대출/보험 중개 수수료 | Engine |
| 25 | **크리에이터 길드/조합** | 개별 크리에이터는 브랜드 대비 협상력이 없음 | COSY 크리에이터 집단 협상력 → 브랜드딜 단가 상승 → 중개 수수료 | Sticky |
| 26 | **AI 크로스보더 현지화** | 번역/더빙/자막 비용이 높음 | AI 자동 번역·더빙·자막 → 글로벌 진출 무료 지원 → 해외 매출 수수료 | Magnet |
| 27 | **크리에이터 IP/저작권 관리** | 법률 비용이 높고, 무단 사용 추적이 어려움 | 무료 IP 등록 + AI 무단사용 감지 → 법률 서비스 중개 수수료 | Sticky |
| 28 | **크리에이터 번아웃 관리** | "돈 안 되는" 영역으로 모든 플랫폼이 무시 | 무료 웰니스 도구 → 크리에이터 충성도 극대화 (떠나야 할 이유를 제거) | Magnet |

## 글로벌 경쟁자 대비 포지셔닝

| 경쟁자 | 그들이 하는 것 | COSY가 더 하는 것 |
|--------|-------------|-----------------|
| **Shopify** | 커머스 | + 콘텐츠 + 크루 + AI 에이전트 |
| **Notion** | 문서·프로젝트 | + 매출 + 정산 + 고객 + 금융 |
| **GPT Store** | 범용 AI 에이전트 | + 크리에이터 비즈니스 데이터 결합 |
| **Linktree** | 링크 모음 | + 정체성 + 신용 + 포트폴리오 + CRM |
| **Discord** | 커뮤니티 | + 커머스 + 정산 + AI 자동화 |
| **Beehiiv** | 뉴스레터 | + 메신저 + 드라이브 + 미팅 + 분석 |
| **Stripe** | 결제 인프라 | + 크리에이터 특화 세금·계약·신용 |

::: tip 한 줄 요약
COSY는 "크리에이터의 Stripe"가 아닙니다. "크리에이터의 AWS"입니다 — 그 위에서 무엇이든 구축할 수 있는 인프라 레이어.
:::
